Sim Racing Chess

This is a python game that you operate with sim racing gears.

The button/axis numbers are specific to my wheel(CAMMUS C5), so check your device. The configuration might be different.

Do anything you want with this code. If you added something new, feel free to send a pr.

Controls
Wheel – move left/right across the board (file)
Gas – move up/down the board (rank)
Brake – grabs/drops a piece
Paddle shift - menu operation

What you need:
Sim Racing gear
Stockfish API and pygame
